# TaskFlow — Vanilla JavaScript Task Manager

TaskFlow is a simple, interactive task-management application built with HTML, CSS and vanilla JavaScript.

The project focuses on strengthening my JavaScript fundamentals through practical application development, DOM manipulation, event handling, arrays, objects and browser storage.

## Features

- Create and add tasks.
- Edit and delete tasks.
- Mark tasks as completed or active.
- Search tasks by keyword.
- Filter tasks by completion status.
- View task statistics and counters.
- Assign due dates to tasks.
- Set task priority levels (Low, Medium and High).
- Automatically save tasks using browser localStorage.
- Preserve tasks after refreshing the browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JavaScript)
- Browser localStorage

1. Clone this repository.
2. Open the project folder.
